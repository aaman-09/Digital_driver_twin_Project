# Drive Twin

A Personalised Driver Behaviour Digital Twin for Real-Time Risk Assessment using Multimodal Sensor Fusion.

## Project Components

- Driver Monitoring
- Drowsiness Detection
- Attention Detection
- IMU-based Motion Analysis
- GPS
- Vehicle Data
- Multimodal Sensor Fusion
- Driver Behaviour Profiling
- Digital Twin
- Risk Assessment
- Explainable Alerts
- Real-Time Dashboard
- Edge Processing

## Technology Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- Pandas
- Scikit-learn
- ESP32
- Raspberry Pi
- SQLite
- Streamlit
